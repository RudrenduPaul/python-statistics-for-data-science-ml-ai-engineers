One rigor gap found and fixed: "Choosing the length-scale" stated that marginal likelihood
maximization is "the default in essentially every GP library" and left it there, without
disclosing that the optimization itself is not guaranteed to reach the best hyperparameter
setting. The marginal likelihood surface for a GP is commonly multimodal (a short-length-scale
peak that reads variation as signal against a long-length-scale peak that reads the same
variation as noise), a documented failure mode of Type-II MLE for GPs, not a hypothetical edge
case. Added two sentences naming this limitation, citing the chapter's existing Rasmussen and
Williams 2006 reference, and pointing at `GaussianProcessRegressor`'s `n_restarts_optimizer`
argument (left at its default of 0 in the chapter's own code example) as the practical fix.
Verified live via WebFetch against scikit-learn's current `GaussianProcessRegressor`
documentation that `n_restarts_optimizer` defaults to 0 and exists specifically to escape local
optima in the log-marginal-likelihood surface; full detail logged in the addendum to
`chapter-11-bayesian-gaussian-processes.plagiarism-report.md`.
